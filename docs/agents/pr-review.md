# Проверка pull request

Независимое ревью запускается отдельно от реализации для PR из этого репозитория. Создайте секрет Actions `OPENCODE_GO_API_KEY` для OpenCode Go и переменную `OPENCODE_MODEL` со значением вида `opencode-go/<model-id>`. Для PR, созданных доверенным ботом, задайте переменную `TRUSTED_PR_BOT`; его ветка должна начинаться с `opencode/`. Без этих настроек запуск модели не состоится.

Секрет доступен workflow на событии PR. Проверка автора и отправителя внутри workflow не является защитой от участника с правом изменить сам workflow в своей ветке. Предоставляйте право записи только доверенным участникам и отдельно проверяйте изменения Actions и доступов. PR из fork не получают секрет.

Автор PR указывает в описании ссылки на обращение, спецификацию, связанные задачи и согласование человека. Ревьюер получает содержимое локальных issue, на которые есть ссылки в описании, и комментарии к PR. Внешние источники, которые он не может прочитать, он должен отметить в ревью. Человек разбирает замечания и сам решает, какие изменения поручить агенту.

Браузерное задание проверяет head SHA PR и сохраняет SHA, результат и Playwright trace в артефакт. Перед мержем откройте артефакт и сравните его SHA с текущим head PR; после нового push повторите проверку. Успешный CI и ревью не заменяют решение человека о мерже.

Интерактивный обработчик `/oc` с лимитом попыток пока не настроен. До его появления команды в комментариях не выполняются автоматически, а доказательство отказа после исчерпания бюджета отсутствует.
