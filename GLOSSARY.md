# Календарь встреч

Термины для записи гостей на встречи с одним заранее заданным владельцем календаря.

## Термины

**Владелец календаря**:
Человек, который задаёт типы встреч и просматривает предстоящие записи.

**Гость**:
Человек, который выбирает тип встречи и записывается на свободное время без регистрации.

**Тип встречи**:
Предложение встречи с названием, описанием и длительностью.

**Свободный слот**:
Интервал времени, доступный для записи на выбранный тип встречи.

**Запись**:
Забронированный гостем интервал времени для встречи выбранного типа.
